# Aggregate evidence

These eight Markdown files are bounded copies of archived aggregate results, not newly computed experiments. Panel A is seed1221, Panel B seed911, and Panel C locked1000. Each controller evaluation has 300 studies; the larger source-audit parent populations must not be combined arithmetically with these subsets.

The six comparison reports contain arm-level and finding-category aggregates plus 5,000-resample subject-cluster intervals. The gate report retains the original retrospective-governance warning. The integrity report retains the complete aggregate table; its detailed source-input section was omitted because it described private generation-artifact filenames. Numeric entries were not edited.

`manifest.json` records exact Git provenance, transformations, and script/input mapping. The preparations are agent verification, not human-author approval or permission to publish.

No participant-level rows, reports, images, credentials, absolute system paths, or protected inputs are included.
